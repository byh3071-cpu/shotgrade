# PRD — ShotGrade

## 해결할 문제
- 홈바리스타/카페 바리스타가 에스프레소 샷의 품질을 객관적으로 측정할 방법이 없음
- "내 샷이 몇 점인지" 알려면 숙련자의 평가가 필요 → 접근성 낮음
- 매일 추출하지만 개선 방향을 모르는 사용자가 대다수

## 핵심 가치
- "에스프레소 사진 한 장으로 2초 안에 AI 등급(A~F) + 구체적 조절 가이드를 받는다"

## MVP 범위 (v1)
- 카메라 촬영 / 갤러리 선택으로 에스프레소 사진 입력
- Claude Vision API로 크레마·색상·추출 분석 → 등급(A~F) + 점수(0~100)
- 분석 결과 카드 UI (등급 뱃지 + 항목별 분석 + 조절 가이드)
- 👍👎 피드백 버튼 (분석 정확도 수집)
- Google OAuth 로그인
- 내 샷 히스토리 리스트 (최신순)
- PWA (모바일 홈화면 추가)

## 제외 사항 (v1에서 하지 않을 것)
- 결제/구독 (Free/Pro/Cafe 플랜은 v2)
- 소셜 기능 (공유, 랭킹, 커뮤니티)
- 그라인더/머신 세팅 자동 연동
- 영상 분석 (사진만)
- 다국어 (한국어 전용)
- 오프라인 분석 (서버 API 필수)

## 유저 스토리
1. 사용자는 에스프레소 샷을 촬영하고 싶다, 왜냐하면 AI 분석을 받으려면 사진이 필요하니까
2. 사용자는 2초 안에 등급과 점수를 보고 싶다, 왜냐하면 추출 직후 바로 피드백이 필요하니까
3. 사용자는 "어떻게 조절하면 되는지" 가이드를 보고 싶다, 왜냐하면 등급만으로는 개선할 수 없으니까
4. 사용자는 과거 샷 히스토리를 보고 싶다, 왜냐하면 추출 실력이 나아지고 있는지 추적하고 싶으니까
5. 사용자는 분석이 틀렸을 때 피드백을 남기고 싶다, 왜냐하면 AI가 더 정확해지길 기대하니까

## Detailed User Flow
1. 앱 진입 → 미로그인 시 Google OAuth → 로그인 완료
2. 메인 화면 → 카메라 촬영 or 갤러리 선택
3. 이미지 클라이언트 리사이즈 (max 1024px, quality 0.8)
4. Base64 → POST /api/analyze → Claude Vision API 호출
5. JSON 응답 파싱 → grade-card.tsx 렌더링
6. 사용자 피드백 (👍/👎) → shots 테이블 feedback 컬럼 업데이트
7. 히스토리 페이지 → 최신순 리스트 → 카드 클릭 시 상세 보기

## 성공 지표
- MVP 배포 후 7일 내 본인 포함 5명 이상 실사용
- 분석 정확도 피드백 👍 비율 70% 이상
- 평균 분석 응답 시간 3초 이내
