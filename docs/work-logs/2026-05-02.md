### Supabase (한 프로젝트·다중 앱 전제)

- DB 테이블은 Postgres 스키마 `**shotgrade`** 에만 둠 (`public.shots` 아님).
- 대시보드 **Settings → API → Exposed schemas** 에 `**shotgrade`** 추가 필수.
- Storage 버킷 `**shot-images`** 는 프로젝트 공용(스키마와 무관).
